Sobre o Discord Clone

Clone completo do Discord com engenharia reversa de UI/UX, executando sem necessidade de banco de dados externo ou backend pesado.

  • Frontend: HTML5, CSS3, Tailwind CSS
  • Sons e Áudio: Web Audio API (Chimes autênticos)
  • Go Live: WebRTC MediaStream + Screen Capture DisplayMedia API
  • Tempo Real: WebSockets e BroadcastChannel para múltiplos navegadores

Transmissão de Tela Bloqueada pelo Navegador

O Chrome/Edge exige conexão segura para Go Live e Microfone

Por segurança, navegadores modernos (Chrome, Edge, Brave) bloqueiam a captura de tela quando acessada por um endereço IP via HTTP (http://26.134.212.76:3000).

⚡ Como liberar a transmissão em 30 segundos no Chrome/Edge:
  1. Abra uma nova aba e acesse:
    chrome://flags/#unsafely-treat-insecure-origin-as-secure (ou edge://flags)
  2. No campo de texto que aparecer, cole o endereço:
    http://26.134.212.76:3000
  3. Altere a opção de Disabled para Enabled.
  4. Clique no botão azul Relaunch (Reiniciar) no canto inferior.
💡 No Render.com (Produção): Quando o projeto for publicado no Render com HTTPS, essa configuração não será necessária! Funcionará direto para qualquer pessoa.
